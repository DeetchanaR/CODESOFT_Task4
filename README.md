# 📚 AI-Based Book Recommendation System

## Overview

This project is developed as part of the **CodSoft Artificial Intelligence Internship (Task 4)**.

The Book Recommendation System suggests books to users based on their interests and preferred genres. By analyzing the selected book, the system recommends similar books from the same category, providing a simple example of a content-based recommendation system.

## Features

* Book recommendations based on genre
* Multiple book categories

  * Self-Help
  * Fantasy
  * Thriller
  * Science Fiction
  * Romance
* User-friendly console interface
* Continuous recommendations until the user exits

## Technologies Used

* Python
* Pandas

## How It Works

1. The user enters the name of a book.
2. The system identifies the book's genre.
3. Similar books from the same genre are recommended.
4. The user can continue exploring recommendations.
